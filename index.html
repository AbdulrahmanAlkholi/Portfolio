About

Hello, I’m Abdulrahman

I’m a Computer Science student at Al Hussein Technical University in Amman, Jordan, passionate about building software across game development, full-stack web development and data science. I enjoy taking an idea and turning it into something functional — whether that means designing a game mechanic, building a complete web application, or finding meaningful insights hidden within a dataset.

My work spans Unity and C# for game design and development, alongside JavaScript, React, Node.js, Express and MongoDB for full-stack development using the MERN stack. I also work with data analysis, processing and visualization, using tools and technologies that help turn raw data into clear, useful information.

My journey in tech began when I was a curious 12-year-old, teaching myself how to program from scratch. I was completely mesmerized by the magic of turning pure imagination into working reality with just a couple of clicks and lines of code. That relentless self-driven curiosity and love for learning haven’t faded — they still fuel every line of code I write and every project I build today.
