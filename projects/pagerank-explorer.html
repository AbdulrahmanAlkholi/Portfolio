Overview

PageRank Explorer is an interactive web crawling and graph visualization project that demonstrates how Google’s original PageRank algorithm can be used to analyze the importance of webpages. The project crawls websites, calculates PageRank scores based on link relationships, and visualizes the resulting network through an interactive browser-based graph.

Technical Focus

  • Built a web crawler and PageRank engine using Python.
  • Stored crawled pages, links, and rankings using SQLite.
  • Implemented iterative PageRank calculations to rank webpages based on their link structure.
  • Used D3.js to create an interactive force-directed graph visualization.
  • Added dynamic node sizing, connection highlighting, tooltips, and ranking information.
  • Created a data pipeline connecting web crawling, database storage, ranking, JSON export, and visualization.

The project strengthened my understanding of graph algorithms, web crawling, data processing, databases, and interactive data visualization, while providing practical experience implementing PageRank from the ground up.
