Overview

Bankist is an interactive banking web application designed to simulate a modern online banking experience. The project focuses on creating a dynamic interface where users can view account activity, manage transactions, and interact with different banking features through the browser.

Rather than being a static website, Bankist uses JavaScript to update the interface dynamically based on user actions and application data.

Technical Focus

  • Built an interactive banking interface using HTML, CSS, and JavaScript.
  • Implemented dynamic transaction and account information.
  • Used JavaScript to update the DOM based on user interactions.
  • Added interactive UI components such as navigation, modals, and tabs.
  • Worked with arrays and objects to process and display account data.
  • Implemented functionality for transferring money and other banking operations.
  • Practiced modern JavaScript concepts including array methods, event handling, and asynchronous programming.

The project strengthened my understanding of JavaScript-driven interfaces, state manipulation, event-based interactions, and building responsive web applications without relying on static content.
