Overview

The Missing Variable is a narrative-driven educational game developed for the HTU Math Marathon 2026. The game transforms traditional mathematics problems into an interactive forensic investigation, where players solve mathematical challenges to analyze evidence and uncover the truth behind a fictional crime.

Rather than presenting mathematics as standalone worksheets, each problem directly affects the investigation, making mathematical accuracy part of the gameplay and narrative.

Technical Focus

  • Developed a 2D game using Unity and C#.
  • Designed a forensic investigation system connecting mathematical problems with narrative evidence.
  • Implemented dynamic case generation with randomized suspects and outcomes.
  • Built a centralized case management system for suspects, rooms, evidence, and challenges.
  • Integrated algebra and trigonometry into practical investigative scenarios.
  • Structured the game’s logic to support adding new cases, problems, and educational content.

The project strengthened my understanding of Unity game development, C# programming, game-state management, dynamic systems, and integrating educational concepts into interactive gameplay.
